About This Project

F1Stats is a full-stack web application built with Spring Boot and MariaDB. It provides a RESTful API for managing Formula 1 data including drivers, teams, races, and race results. The frontend uses Bootstrap 5 and jQuery to provide a clean, responsive interface.

Spring Boot 4.0 Spring Data JPA Hibernate MariaDB Bootstrap 5 jQuery REST API Git & GitHub Java 17 Maven
